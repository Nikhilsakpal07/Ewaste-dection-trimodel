MODEL 01 // PRODUCTION
⚡

YOLOv8 (Anchor-Free SOTA)

Modified CSPDarknet with C2f modules and split decoupled head. Directly regresses bounding box borders without anchor hyperparameter clustering. Maximizes inference FPS on live cameras.

Backbone: C2f Gradient Fusion Head: Decoupled Box & Cls Loss: CIoU + DFL + BCE
MODEL 02 // BASELINE
🎯

YOLOv5 (Anchor-Based Baseline)

Proven single-stage baseline utilizing CSPDarknet53 with C3 bottleneck modules and PANet multi-scale feature pyramids. Evaluates k-means clustered anchors across varied hardware geometry.

Backbone: C3 Cross Stage Partial Neck: PANet + SPPF Loss: CIoU + Objectness + Cls
MODEL 03 // TWO-STAGE
🔬

Faster R-CNN (ResNet-50-FPN)

Academic two-stage gold standard. Utilizes a Region Proposal Network (RPN) followed by RoIAlign to sample sub-pixel feature patches. Superior precision in heavily cluttered scrap piles.

Backbone: ResNet-50 (50 Residual Layers) Neck: Feature Pyramid Network (FPN) Stage 2: RoIAlign + 1024-D FC Predictor
